SECÇÃO G — Botão "Testar Ligação"
O que o botão deve executar internamente:
1. Validar se todos os campos obrigatórios estão preenchidos
2. Carregar certificado e credenciais configuradas
3. Consoante o protocolo:
   │
   ├── SOAP → Enviar envelope de autenticação/ping ao WSDL
   │          Verificar resposta do serviço (HTTP 200 + envelope válido)
   │
   └── REST → POST para URL do token com Client ID + Secret
              Verificar se retorna access_token válido
              GET para endpoint de health/status da API
4. Registar resultado em: sdd_last_connection_test
                          sdd_last_connection_status
                          sdd_last_connection_log
5. Mostrar resultado na interface
