## 2. Campos Obrigatórios para a Integração EMIS (GPO)
Quando o teu código comunica com a API da EMIS para iniciar o Webframe, estes são os campos que **não podem faltar** no JSON e que devem ser alimentados pelas tuas tabelas de parametrização e de vendas:
| Campo Técnico | Tipo | Origem no Sistema | Descrição |
|---|---|---|---|
| **merchantId** | String | Configurações Técnicas (Admin) | Identificador único da tua empresa fornecido pela EMIS. |
| **terminalId** | String | Configurações Técnicas (Admin) | Identificador do terminal virtual que processa a venda. |
| **merchantReference** | String | Motor de Vendas (Backend) | Código único da transação gerado pelo teu sistema (essencial para a reconciliação). |
| **amount** | Decimal | Carrinho de Compras | O valor total a ser cobrado ao cliente. |
| **currency** | String | Fixo / Configuração | Código ISO da moeda. Para a rede Multicaixa, o padrão obrigatório é **AOA**. |
| **returnUrlSuccess** | String | Configurações Técnicas (Admin) | URL do teu site para onde o cliente é redirecionado após pagar com sucesso no Webframe. |
| **returnUrlFail** | String | Configurações Técnicas (Admin) | URL do teu site caso o pagamento falhe ou seja cancelado. |
| **timestamp** | String | Backend (Tempo Real) | Data/Hora no formato ISO 8601 para evitar ataques de *replay* de transações. |
| **signature / hash** | String | Função Criptográfica | O resultado do emparelhamento dos dados acima com a **Secret Key** do Admin através de HMAC-SHA256. |
